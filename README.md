# Mohith Shetty — Developer Portfolio

A responsive, dark-themed React portfolio built with Vite and Lucide icons.

## Run locally

1. Install Node.js (LTS).
2. Open this folder in a terminal.
3. Run `npm install`.
4. Run `npm run dev`.
5. Open the local URL printed by Vite.

## Before publishing — personalize these details

- Replace `YOUR_EMAIL@example.com` in `src/main.jsx` with your real email address.
- Replace the generic GitHub and LinkedIn profile links with your profile URLs.
- Add your actual graduation year, current semester, certifications and verified skills.
- Add project repository/demo links and screenshots when available.
- Review every project description and status so it accurately reflects your current progress.

## Build for deployment

Run `npm run build`. The production website is generated in the `dist/` folder. You can deploy it to Vercel, Netlify or GitHub Pages.
